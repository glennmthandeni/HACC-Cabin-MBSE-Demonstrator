# Capella model

Import the `HACC_MBSE_Architecture` folder as an existing Eclipse project and open
`HACC_MBSE_Architecture.aird` in Capella 7.1.0. The session contains 18 native
representations and references the semantic and metadata files by canonical name.

See [`../docs/opening_in_capella.md`](../docs/opening_in_capella.md) for the complete
workflow.
