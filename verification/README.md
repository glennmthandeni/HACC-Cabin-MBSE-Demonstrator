# Verification strategy

The verification programme follows a staged evidence path from material properties
to representative aircraft operation.

| Gate | Focus | Decision evidence |
|---|---|---|
| G1 | Material screening and porous-property characterisation | Controlled material data and fitted model inputs |
| G2 | CFRP–HACC coupon and resonator characterisation | Measured TL, damping and absorption; ±3 dB model correlation target |
| G3 | Cabin mock-up, integration and maintainability | Installed insertion loss, room-field change and maintenance demonstration |
| G4 | Seated/bed active-control rig and fault response | Stable attenuation in both postures and verified protection behaviour |
| G5 | Matched A/B cruise flight test | Broadband and narrowband passenger results for qualification decisions |
| EXT | Status and diagnostic boundaries | Read-only status and selected diagnostic exchange checks |

`verification_cases.csv` maps each case to one or more requirement IDs and defines
the expected evidence. All cases are currently `PLANNED`. Results and evidence
should be added only after the corresponding activity is executed.
